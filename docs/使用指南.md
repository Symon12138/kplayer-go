# KPlayer 使用指南（Web 控制台）

面向第一次使用的运营人员。控制台地址：**http://<服务器IP>:4156/console/**（无需登录，内网自用）。

---

## 一、5 分钟快速上手

假设你有一台服务器，上面有视频文件，想推流到一个直播平台。

1. **登记媒体**：左侧「媒体库」→「登记媒体」→ 填视频**绝对路径**（如 /video/demo.mp4），或填**整个视频目录**（目录自动按排序方式逐集连续播放）→ 添加。
   也可以「扫描目录」批量登记（可勾选探测时长/分辨率）。
2. **快速推流**：左侧「多路推流」→「快速推流」→ 选内容 + 填推流地址（rtmp://...）→ 点「开始推流」，立即推流（1280x720 / 2500kbps / 25fps / H.264 默认参数，无需任何手动配置）。
3. **确认推流成功**：总览页或任务行显示「运行中」。
   （可用 ffprobe 验证：ffprobe -i rtmp://127.0.0.1:1935/live/main）
4. **多线路/多任务**：需要同时推多条线路或多个内容 → 「多路推流」→「新建推流任务」→ 选内容 + 「+ 添加线路」填多个 RTMP 地址（可多条）→ 保存 → 启动。
5. **停止**：任务行「停止」，或总览页「停止」。

> 所有配置都有默认值：ffmpeg 自动检测、断线自动重推 5 秒、输出参数预填常用档位，
> 无需手动配置任何路径。

## 二、日常运营流程（从内容到播出）

### 1. 内容准备 →「媒体库」
- 登记单个视频 / 扫描整个目录
- 支持视频与音频；可看时长、分辨率、大小
- 删除用「移除」

### 2. 节目编排 →「节目单」
- 新建节目单：填名称 → 从媒体列表「+ 添加条目」→ 可勾选**循环**、可选**后备节目单**（主节目单异常时自动切换）
- 列表支持上下移动排序、删除条目

### 3. 自动播出 →「定时任务」
- 新建任务：填名称 → 类型选**间隔**（每 N 秒）或**定时**（cron 五段式）→ 目标选节目单或单个媒体 → 启用
- 行内可编辑（Edit）、禁用/启用（Disable/Enable）、删除
- 任务到点自动驱动播放

### 3·5. 多平台不同内容 →「多路推流」（核心页）

- **快速推流**：选内容 + 一个推流地址，一步开始
- **推流任务**：一个任务 = 一个内容 + **多条输出线路**（「+ 添加线路」，每条线路独立分辨率/码率），同时推多个平台
- 多个任务可并行：**任务 A 推新闻、任务 B 推纪录片**同时进行，互不影响；内容可以是单文件或整个目录
- 任务独立「启动/停止/编辑/删除」；任务定义持久化（重启保留）；断线自动重推默认 5 秒

### 4. 当前推流与应急插播 →「总览」
- 播放目标（媒体/目录/节目单）+ 起始位置 + 随机播放；暂停（挂起推流并记住位置）/继续（恢复）/跳过（切下一个内容）/停止
- **插播**：选目标 + 时长（秒）→「立即插播」，到时自动回到原内容

### 5. 内容与合并 →「媒体库」
- 登记单个视频文件或整个目录；目录按排序方式（文件名/修改时间/随机）逐集连续播放
- 登记时可配**外挂音频**（替换原音轨）和**字幕文件**（烧录进画面）；推流自动合并
- 扫描目录批量登记；支持常见视频格式（mp4/mkv/flv/avi/mov/ts/webm 等）

## 三、页面速查（仅 5 个推流操作页面）

| 页面 | 用途 |
|---|---|
| 总览 | 推流状态 + 当前推流操作（播放目标/暂停/继续/跳过/停止/应急插播） |
| 多路推流 | **核心页**：快速推流（选内容填地址一步开始）+ **推流任务**：一个任务可添加多条输出线路同时推流，任务各自独立内容与平台，独立启动/停止/编辑/删除 |
| 媒体库 | 登记**单个文件或整个目录**（目录按排序方式逐集连续播放）、外挂音频/字幕、扫描；支持常见视频格式 |
| 节目单 | 编排顺序、**四种播放方式**（顺序一遍/顺序循环/随机一遍/随机循环）、可添加**文件或整个目录**为条目、后备节目单 |
| 定时任务 | 按计划自动播放（间隔或 cron 定时），页面有用途说明 |

> 播放控制、推流引擎页已移除：引擎配置全部自动（ffmpeg 自动检测、断线重推
> 默认 5 秒、输出参数预填 1280x720/2500kbps/25fps），操作集中在多路推流与总览。
> 输出分组/主备切换/健康策略/缓存任务/场景模板/插件/Webhook/智能规则/数据分析/
> 告警/系统设置等页面已从界面移除（后端 API 保留，数据不受影响）。

## 四、内容与合并

- **单文件**：登记一个视频文件直接推流
- **目录**：登记整个视频目录，播放时按排序方式（文件名/修改时间/随机）逐集连续播放，播完一集自动切下一集
- **节目单**：条目可以是文件或整个目录；四种播放方式控制整单播放
- **视频+音频+字幕合并**：登记媒体时可配外挂音频（替换原音轨，自动转 AAC）和字幕文件（**烧录进画面**，RTMP 不支持字幕轨）；推流时自动合并成一路

## 四、Web 能配 vs 需要改文件

**Web 可完成（日常全部）**：媒体（文件/目录/外挂音字幕）、节目单（四种播放方式）、定时任务、多路推流任务（多线路）、快速推流、当前推流控制、应急插播、断线重推——全部推流操作。

**需要改文件/启动参数（仅首次部署，之后不再动）**：
1. **端口**：默认 4155（gRPC）/ 4156（HTTP），改 `config.json` 或启动参数
2. **鉴权**：默认关闭；开启需启动参数（`--auth-token`），开启后先在「用户管理」建账号再登录
3. **Docker 数据目录**：`docker-compose.yml` 的 `./data`、`./video` 挂载

---

## 五、数据与持久化

- 所有 Web 操作实时落盘：`management.json`（业务数据）、`engine.json`（引擎配置）
- 重启进程/容器/服务器，数据都在（Docker 部署已实测重启+重建保留）
- 「配置快照」页可手动备份/回滚

## 六、常见问题

- **推流没有开始/任务状态"已停止"**：检查推流地址是否可达（目标平台地址/端口）、ffmpeg 是否安装（自动检测，若系统无 ffmpeg 需安装）
- **播放失败（exit 255）**：多为视频文件损坏或不含可解码流，换一个测试视频
- **想多路同时推**：新建推流任务，「+ 添加线路」加多个输出即可；不同内容就建多个任务
- **任务不触发**：检查任务是否「启用」、目标节目单是否非空、调度器是否运行（总览页）
